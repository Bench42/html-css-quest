# HTML/CSS Quest

Браузерная игра для обучения HTML и CSS с нуля. Сюжет: игрок приезжает в город Боксбург, где умер дядя Флекс и оставил участок у моста и чертёж таверны. Чтобы построить таверну, игрок проходит 10 мастеров: у каждого урок, тренировка и стройка по чертежу. Код игрока проверяется по структуре (DOMParser), результат виден в превью.

## Как работать со мной (Максим)
- Отвечай по-русски, коротко.
- Сначала план, потом изменения; без плана только если я сказал «делай».
- Я учусь: перед каждым шагом объясняй простыми словами, что делаем и зачем. HTML и CSS знаю, JavaScript, React и Git нет.
- Если задача неясна, задай 1-2 коротких вопроса.

## Стек
Vite + React (JavaScript), Tailwind CSS, позже CodeMirror 6 и PWA. Публикация: GitHub Pages, репозиторий Bench42/html-css-quest. Бесплатно, без серверов.

## Принципы
- Телефон в приоритете. Прогресс в localStorage (ключ hcq_save1).
- Содержание мастеров в отдельных файлах, движок проверки отдельно.
- Python Quest не трогаем (другой репозиторий).
- Прототип главы 1 (один HTML-файл) лежит в папке reference и считается эталоном поведения.
